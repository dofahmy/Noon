# NoonDealsEgy v17 — التأكد من نشر الكود الصحيح

هذه الحزمة مبنية على الملفين المرفوعين `noon_forwarder(2).py` و`yajny_links(2).py` مع **تصحيح أسماء الملفات التشغيلية** وإضافة سطر تعريف واضح عند بدء تشغيل البرنامج. لا تتضمن أسرار أو جلسات.

## أهم تشخيص
الرسالة القديمة `Post has no recognized Noon/Yajny product URL; refuse publish` **غير موجودة في هذه الحزمة**. إذا ظلت تظهر بعد تحديث الخدمة، فالكود النشط ليس الملف الموجود هنا، أو أن السطور من Deployment قديم.

## التحديث
1. ارفعي محتويات مجلد ZIP إلى جذر مستودع GitHub المرتبط بخدمة نون. أسماء الملفات المهمة بالضبط: `noon_forwarder.py`, `yajny_links.py`, `Dockerfile`, `requirements.txt`.
2. لو عندك ملفان `noon_forwarder.py` و`noon_forwarder(2).py`، **استبدلي الأول بمحتوى الجديد** ولا تعتمدي على الثاني. وينطبق نفس الشيء على `yajny_links.py`.
3. اعملي Commit ثم راقبي Railway > Deployments للتأكد أن نفس الـCommit أصبح Active. أوقفي أي خدمات مكررة تنشر لنفس القناة.
4. في الـDeploy Logs الجديدة، ابحثي بكلمة واحدة `VERSION`. لازم يظهر `VERSION v17 VERIFIED MIXED AMAZON+NOON` ومعه `executing=/app/noon_forwarder.py` (قد يختلف المسار وفق Docker).
5. لا تحذفي Volume `/data` أو قاعدة البيانات ولا تغيري جلساتك/Variables. احتفظي بنسخة احتياطية إن أمكن.
6. بعد التحديث المتوقع عند بوست بلا رابط منتج: `IGNORED NON-PRODUCT`. وعند عرض أمازون أو نون معروف: `NEW` أو `ALBUM`، أو `NO PUBLISH` مع سبب محدد إن فشل التحويل.

## الخصائص المحفوظة
النشر في `@NoonDealsEgy`، أمازون `fromnoony-21`، نون يجني، فوتر قناة أمازون، أكواد HZ26–HZ30، منع تكرار المنتج 24 ساعة، وتحديث الصور والنصوص.

**ملاحظة:** تمت مراجعة وفحص صياغة Python في هذه الحزمة؛ لم يتم تنفيذ نشر حي على Railway أو التحقق من إنشاء روابط يجني عبر الحساب.
