اختبار مستقل لإنشاء رابط واحد من يجني (بدون تليجرام)
====================================================

الاختبار ينقر «إنشاء رابط» مرة واحدة فقط باسم AUTO-TEST-001.
لا ينسخ أو ينشر أي بوست على قناتك ولا يعدل قاعدة البيانات.
المنتج التجريبي الافتراضي: رابط نون سبق استخدامه في المحادثة؛ ممكن تغييره.

تشغيل على الكمبيوتر Windows:
1- فكّي الضغط وافتحي PowerShell داخل المجلد.
2- py -m pip install -r requirements.txt
3- py -m playwright install chromium
4- لو عندك ملف yajny_session_PRIVATE.txt محفوظ من قبل، حطيه داخل المجلد محليًا (لا ترفعيه إلى GitHub ولا ترسليه لأحد).
   أو شغلي py bootstrap_yajny.py وسجلي دخولك واحفظي الجلسة.
5- أوقفي خدمة النسخ مؤقتًا لتجنب إرسال محاولات إضافية أثناء الاختبار.
6- py test_yajny_once.py

لو عايزة رابط نون مختلف:
$env:TEST_NOON_URL="https://www.noon.com/egypt-ar/PRODUCT/p/?o=OFFER"
py test_yajny_once.py

راقبي النتيجة في PowerShell: CLICKED_CREATE: once ثم CREATE_POST_STATUS و TEST_NAME_FOUND_IN_HISTORY.
افتحي «الروابط السابقة» في يجني واتأكدي يدويًا من ظهور AUTO-TEST-001.

مهم: لو اختبرتي الاسم بالفعل، لن ينشئه من جديد إذا وجده في الصفحة الأولى. عند إعادة الاختبار بعد نجاح سابق استخدمي اسمًا جديدًا في نسخة الاختبار فقط، حتى لا تكرري الروابط.
لا تشاركي جلسة يجني أو Cookies أو ملفات التخزين. الاختبار لا يطبعها.
