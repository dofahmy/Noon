سبب الخطأ: كتابة await داخل generator expression عند فحص عدد حقول النموذج تسببت في TypeError: async_generator object is not iterable.
تم استبدال التعبير بانتظار count() لكل حقل على حدة قبل التحقق.

طريقة التحديث: ارفعي ملفات هذه النسخة إلى نفس خدمة نون فقط، ولا تحذفي /data أو قاعدة البيانات، واحتفظي بالمتغيرات والجلسات.
الاختبار: فحص تجميعي للبايثون؛ لم يُختبر تسجيل الدخول أو إنشاء رابط حي.
التوقع: اختفاء الخطأ async_generator، ثم تظهر سجلات CREATE_CLICKED/CREATE_POST_STATUS وقد يظهر Yajny created own link عند نجاح يجني.
