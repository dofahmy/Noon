# NoonDealsEgy Forwarder

## الوظيفة
- يراقب @Hi_pro1 و @tawfiry ويعيد نشر البوست بصورته ونصه وروابطه الأصلية على @NoonDealsEgy، **بدون Forward**.
- يستبدل فقرة الكوبونات عندما يتعرّف على بدايتها، أو يضيف فقرة الأكواد إن لم يجدها.
- الأكواد HZ26 إلى HZ30 تظهر بصيغة `Code` القابلة للضغط للنسخ في تليجرام.
- يراجع آخر 100 بوست بكل قناة دوريًا لتعديل النص عند تعديل الأصل. يحتفظ بقاعدة بيانات لمنع التكرار.
- النسخ الأولي الافتراضي لآخر 20 رسالة من كل مصدر، ثم يلتقط الجديد ويحدّث القديم.
- إذا كان المنشور طويلًا ولا يتسع لكابشن الصورة، يضع النص في رسالة تالية.

## تشغيل محلي Windows PowerShell
```powershell
py -m pip install -r requirements.txt
$env:TELEGRAM_API_ID="YOUR_ID"
$env:TELEGRAM_API_HASH="YOUR_HASH"
py create_session.py
```
احتفظي بقيمة `TELEGRAM_SESSION_STRING` سرًا. ثم:
```powershell
$env:TELEGRAM_SESSION_STRING="THE_GENERATED_STRING"
$env:TELEGRAM_SOURCES="Hi_pro1,tawfiry"
$env:TELEGRAM_DESTINATION="NoonDealsEgy"
$env:DATA_DIR="./data"
py noon_forwarder.py
```

## تشغيل Railway
- ارفعي محتويات المجلد إلى مشروع Railway مستقل.
- Start Command: `python noon_forwarder.py`
- أضيفي متغيرات `.env.example`، واستبدلي القيم السرية.
- ربط Volume بـ `/data` للحفاظ على قاعدة بيانات `noon_mirror.sqlite3` بين إعادة التشغيل (مهم لمنع النسخ المكرر).
- شغّلي Replica واحدة فقط. لا تشغلي البرنامج محليًا على نفس الجلسة بالتزامن مع Railway.
- لازم حساب التليجرام المستخدم يكون عضوًا بالقناتين وقادرًا على النشر بصفة أدمن في @NoonDealsEgy.
- لو لا تريدين نسخ المنشورات القديمة في أول تشغيل، اجعلي `BACKFILL_LIMIT=0` (لكن أول تشغيل بدون Backfill لا يقوم بنسخ المنشورات التاريخية).

## تنبيهات
- روابط المنتجات/الأفلييت تظل كما هي: هذا البرنامج **لا يغيّر تتبع الأفلييت** ولا يفتح الروابط المختصرة.
- إذا تغيّرت صور منشور موجود لاحقًا، سيحدث النص فقط؛ تغيير الصور/محتويات الألبوم يتطلب معالجة مستقلة.
- بعض الحالات النادرة مثل رسائل التصويت والمحتوى المقيّد من النسخ أو ملفات غير مدعومة قد تفشل وتظهر في Logs.
- إذا كان المصدر يستخدم فقرة أكواد غير معروفة فلن يتم حذفها تلقائيًا، لتجنب حذف وصف المنتج بالخطأ؛ يمكن إضافة نمط جديد في `COUPON_START`.

## إصلاح 7 نوفمبر 2026 (PhotoSize)
أُصلح خطأ `AttributeError: 'PhotoSize' object has no attribute 'location'` في المنشورات الفردية والألبومات عبر استخدام معرف الصورة/المستند الأصلي بدل `msg.file.id`.
لا تمسح مجلد `/data` أو ملف `noon_mirror.sqlite3` عند التحديث؛ الاحتفاظ بقاعدة البيانات يمنع إعادة نشر المنشورات القديمة.
إذا لاحظت `EDIT` مرة واحدة لبعض المنشورات بعد التحديث فهذا نتيجة تغير طريقة بصمة الوسائط، ولا يعني إعادة نشرها.
